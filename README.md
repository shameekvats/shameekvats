## What I work on

- **Materials R&D** — electrospinning and polymer processing: solution rheology, spinning
  setups, characterisation (FTIR, SEM, rheology, mechanical testing).
  Publications on [Google Scholar](https://scholar.google.com/citations?user=xbwnYzYAAAAJ).
- **Design & fabrication** — parametric CAD in Onshape, FDM printing, functional prototypes.
  Through [Tattva-3D](https://t-3d.me) I print and design parts on request in Aalborg.
- **Self-hosting & embedded** — Raspberry Pi, micro:bit, Linux, Docker.
- **Web** — sites built with Jekyll and Astro + Tailwind.
